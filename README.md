— specialty coffee at Voldersgracht 6, Delft.

Live at **https://chenxi981211-ui.github.io/LOT-coffee-boutique-site/**

A static page: no build step, no dependencies. Menu with order-ahead tickets you
show at the counter, reviews and photos from the shop's Google listing, live
opening-hours status, English/Dutch and light/dark.

This repository is a published mirror — it is updated from the working repo by a
deploy script, so edits made here will be overwritten.
